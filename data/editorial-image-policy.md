# Editorial imagery

Latest editions: 2026-10-25 and 2026-11-01. Media records are keyed by stable card ID in `editorial-images.json`; historical editions without a record remain unchanged.

- Use only verified public-domain, CC0, CC BY or CC BY-SA assets which permit free reuse without an individual permission request. Retain attribution, source-page and licence links. Respect non-copyright warnings and avoid uncertain architecture/artwork rights.
- Commons is a repository, not a blanket licence: check each file's author, licence, description and restrictions. The JSON records the capture date as provided by the source and the date checked. Do not treat upload dates as known capture dates.
- All brief images in this batch are contextual FILE PHOTOS, not images of the reported incidents. Captions identify the pictured subject and year; train, school, care-policy and cyber images explicitly avoid identifying unrelated people or organisations as victims or participants.
- Copy permitted assets into `public/images/editorial/` for reliable hosting. Show clickable author/source and licence credits alongside every image. CSS crops images; portraits also receive grayscale styling. Captions disclose changes. The applicable source licence continues to apply to these adaptations, including share-alike where required; it does not relicense the site's unrelated text or code.
- Portraits identify the actual named author. Do not invent portraits for institutions, substitute another person, or use a photo merely because an author's website displays it. Missing licensed portraits have no placeholder or missing-image warning.
- Reserve image space, lazy-load, preserve English-first bilingual captions and alternative text. On image loading errors, hide the figure rather than displaying a broken-image icon.
- Future updates: verify licence/source, inspect the actual downloaded asset visually, check caption accuracy, test mobile/desktop cards and carousel, run tests/build, then publish via the existing GitHub/Cloudflare workflow.
