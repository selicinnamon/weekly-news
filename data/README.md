- 生育与写作：评论的价值判断、访谈材料及因果证据分别表达。

## 字段及后续使用

`Topic.id` 是可跨周复用的议题标识，`articleId` 标识具体原文，`BriefItem.id` 按期唯一。原刊印刷页码与 PDF 页序分别存储；如 WSJ B1/B4 对应 PDF 15/18，New Yorker 62–65 对应 PDF 64–67，Guardian Journal 3 对应 PDF 47。

中英文摘要、背景、论点、证据与标签成对保存；推荐理由、局限、反方检验属于编辑判断。英文为原创新闻式转述，不提供全文翻译。外部核查链接就近显示，官方/当事方资料不伪装成独立审计。

原始 PDF、抽取全文、页面截图和 OCR 中间文件留在站点仓库之外，禁止提交或公开。代码测试验证字段、数量、覆盖与渲染；它们不能替代事实核验或用户的阅读质量评价。预计阅读时间尚未经过用户实测。
